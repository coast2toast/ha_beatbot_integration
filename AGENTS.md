# Repository Instructions

## Attribution and privacy

- Use `coast2toast` for maintainer, copyright, release, and project attribution.
- Use the GitHub noreply identity for `coast2toast` when commit metadata is required.
- Do not add personal names, personal email addresses, household identifiers, credentials, tokens, private network details, or Home Assistant runtime data to repository files, commits, tags, releases, or documentation.
- Before publishing, scan both the working tree and reachable Git history for prohibited personal or secret data.
