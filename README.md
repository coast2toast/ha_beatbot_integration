# Home Assistant Projects

Persistent workspace for Home Assistant integrations, automations, dashboards, documentation, and supporting tools.

## Structure

- `custom_components/` — custom Home Assistant integrations
- `automations/` — reusable automation packages and blueprints
- `dashboards/` — Lovelace dashboard resources
- `docs/` — architecture notes and operating procedures
- `tests/` — automated validation

Secrets, runtime state, backups, logs, and Home Assistant's `.storage` directory must not be committed.
